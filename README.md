# RESOLUTE Lacrosse Customizer

Web app for iPhone, Android and desktop.

**Open the app:** https://07osu49.github.io/ResoluteCustomizerWeb/

On iPhone, open the link in Safari, tap Share, then **Add to Home Screen**. On Android, use your browser's **Install app** or **Add to Home Screen** option. After the first successful visit, the customizer can also load offline; sending email still requires connectivity.

## Current version: V146

- Six, four and two top-string options with horizontal spans behind the head.
- Doubled loose shooter ends, with extra top corner extensions removed.
- Head, mesh, string and shooter colors, thickness, pocket and decal controls.
- Image export and email handoff.

This is a static web app with no build step. GitHub Pages publishes `main` from the repository root. Edit `index.html` and increment the cache version in `sw.js` when releasing updates. The app opens the device's mail/share tools; it does not submit an order to a server.
